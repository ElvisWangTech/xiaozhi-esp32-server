# 技能广场

## 当前范围

- 超级管理员维护两类技能目录：远程 MCP 工具和文本型 `SKILL.md` 技能包；均支持草稿、发布、编辑和下架。
- 超级管理员可选择任意用户及其智能体代为开通/解绑技能；普通用户只能为自己有权限的智能体配置技能。
- 管理端提供精选开源技能包一键导入；只从服务端内置的 GitHub `SKILL.md` 白名单地址取文本（要求 manager-api 能访问 `raw.githubusercontent.com`），导入为草稿，审核后再发布。导入不会下载仓库压缩包、脚本或其他附件。
- 普通用户选择自己有权限管理的智能体，为其开通或解绑已发布技能。
- MCP 类型由管理员配置远程 WebSocket MCP endpoint。技能包类型保存纯文本 `SKILL.md` 和可选 Markdown 参考资料，可附来源链接和许可证；不接受压缩包、附件或脚本上传，也不会执行包内脚本。
- 技能包与 MCP 可分别开通并组合使用：MCP 提供工具，技能包提供提示词指令。
- 技能广场 MCP 与现有智能体专属 `mcp_endpoint` 并存。工具名以 `skill_<skillCode>_` 命名空间注册，避免不同技能中的同名工具互相覆盖。
- 本版尚未接入沙箱。配置的 MCP endpoint 会由 `xiaozhi-server` 直接连接；生产发布前应完成隔离运行时、凭据加密和网络策略设计。

## 使用方式

1. Liquibase 启动时创建 `ai_skill`、`ai_agent_skill` 两张表。
2. 超级管理员进入「技能广场」，新增技能并选择类型：MCP 类型填写 `ws://` / `wss://` 地址；技能包类型粘贴 `SKILL.md` 和可选参考文档的 Markdown 文本，可登记来源链接和许可证。
   也可在管理员的「推荐技能包」区域直接安装精选包；系统只导入其 `SKILL.md`，保存为草稿，参考文件和脚本不会自动导入。
3. 将技能状态设置为「已发布」。草稿和下架技能不会展示给普通用户，也不会下发到语音服务。
4. 普通用户在同一页面选择自己的智能体，开通或解绑技能。
5. 设备下次建立 WebSocket 连接并拉取智能体配置时，`manager-api` 下发其已开通技能。技能清单变化目前在设备下次重连后生效。

## 运行时行为

`ConfigServiceImpl.getAgentModels` 分别返回 `marketplace_mcp_skills` 和 `marketplace_skill_packages`。`xiaozhi-server` 为每个 MCP 技能创建 MCP client，并注册类似 `skill_calendar_list_events` 的工具名；技能包文本则注入该智能体的系统提示词，限制总注入长度。原有 `mcp_endpoint` 字段和 executor 不变。

## 本版限制

- 技能 endpoint URL（可能包含查询参数 token）保存在数据库中；管理员接口可读取该值。当前没有独立的凭据密文存储或沙箱执行，不应将不可信 MCP endpoint 暴露给生产租户。
- 技能包文本会进入绑定智能体的系统提示词，因此管理员应审查来源、许可证和指令内容；文本只作为提示词，不会被当作代码执行。
- 每个设备会话分别连接已开通的共享 MCP endpoint；上线前应压测连接数、远端配额和重连风暴。
- 技能下架或解绑会阻止后续配置下发；已建立的设备会话要等断开/重连后才会刷新工具。
